# 急症早期识别与自救指引

（以下为演示语料，非真实医疗建议，仅供系统功能演示）

## 卒中（中风）
牢记 FAST 口诀：Face 面部歪斜、Arm 肢体无力、Speech 言语含糊、Time 立即拨打120。发病后尽快送达有卒中中心的医院，把握黄金救治时间窗。

## 胸痛心梗
急性胸痛伴大汗、濒死感，立即原地休息并呼叫120；在无禁忌且明确可用时嚼服阿司匹林，等待急救人员送达，避免自行活动。

## 窒息
进食时突然不能发声、面色青紫、双手掐颈，立即实施海姆立克急救法；婴儿采用拍背结合压胸法，同时呼叫急救。

## 跌倒外伤
头部着地后出现意识改变、呕吐或耳鼻漏液，警惕颅内出血，应保持平卧、避免随意搬动，立即呼叫120送急诊。
